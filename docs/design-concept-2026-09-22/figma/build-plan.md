# Редактируемый макет Маэстро

Файл: https://www.figma.com/design/E8PYnYunMXzmYUJuraZ6n2

Источник оформления — четыре PNG-концепции, созданные в предыдущем шаге по макету пользователя. Из кода берутся права сотрудников и статусы, не визуальная тема существующего frontend. Code Connect не найден; новый файл пуст. Проверены доступные библиотеки и найдены общие компоненты SDS, однако фирменных зелёных токенов нет. Для владения и редактирования выбранной темы создаются локальные компоненты и стили Manrope. Шрифт и начертания проверены через Figma API.

Объём: четыре экрана 1440 px, публичные главная/каталог, кабинет менеджера с заявками, кабинет администратора с каталогом. Общие кнопки, поля, статусы, шапки, подвал, карточки работ и строки таблиц — экземпляры локальных компонентов. Базовые цвета, отступы и скругления связаны с переменными. Фотографии — растровые заливки; текст и элементы интерфейса — нативные слои.

API Figma вызывается небольшими порциями. Идентификаторы хранятся в state.json. Макеты собираются из JSON-рецептов; окончательная проверка включает размеры слоёв, шрифт, структуру и изображения экранов.
